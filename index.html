Why it matters

৳

Higher cost

AI APIs bill per token. If a Bangla message takes 5× the tokens, a Bangladeshi startup pays 5× for the same feature.

⏱

Slower replies

Models write one token at a time. More tokens for the same answer means users in Bangla wait longer.

▤

Less memory

Every model has a context window measured in tokens. Bangla fills it faster, so the model can read less of your document.

Why does it happen?

Tokenizers learn their vocabulary from training data that is mostly English. Common English words become a single token. Bangla letters are rarer in that data, and each one is 3 bytes in UTF-8, so the tokenizer often falls back to splitting a single letter like ক into 2 or 3 byte-tokens. Newer tokenizers with bigger, more multilingual vocabularies (compare GPT-4 with GPT-4o) close much of the gap.
